Willkommen — verbinde dein GitHub-Konto

Deine Repositories, Sterne, Aktivität, Issues, Actions und Backups — alles lokal auf deinem PC. Du nutzt deinen eigenen GitHub-Zugang; es gibt kein separates HorosHub-Konto.

Empfohlene Scopes: repousernotificationsread:orgworkflow
Neuen Fine-grained Token auf GitHub erstellen
Lädt öffentliche Repos, Profil und Aktivität. Private Repos und Schreibzugriff kannst du später jederzeit per Token ergänzen.
Dein Token verlässt deinen PC nicht: er wird ausschließlich lokal gespeichert und direkt an api.github.com gesendet. HorosHub betreibt keinen eigenen Server-Dienst.
